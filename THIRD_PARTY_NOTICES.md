O driver SQLite distribui avisos próprios de código transpílado e dependências transitivas; o inventário upstream completo e os textos associados foram copiados para [`LICENSES/modernc-sqlite/`](LICENSES/modernc-sqlite/). Ele inclui componentes condicionais (como `sqlite-vec`) que este programa não importa. A licença da implementação SQLite é de domínio público; a licença MIT do `sqlite-vec` também está preservada por acompanhar o arquivo de avisos upstream.

Este inventário cobre módulos diretos/indiretos declarados em `go.mod` e os avisos transitivos do driver SQLite. `github.com/aymanabagabas/go-osc52/v2` é dependência indireta de suporte terminal em alvos específicos e não é importada no build Linux local; o texto MIT está preservado, mas a matriz multiplataforma deve confirmar a origem do módulo antes de release. O módulo `go-localereader` declara MIT no README sem distribuir arquivo separado; a cópia registra essa licença e atribuição do autor. Não substitui avaliação de compatibilidade nem cobre ferramentas, dependências de desenvolvimento ou todos os dados distribuídos. Confira versões e licenças antes de cada release. Revisão jurídica e checagem dos dados continuam pendentes antes de publicação pública.

## Dados de segurança

O snapshot `internal/code/advisories.json` contém dados selecionados do [GitHub Advisory Database](https://github.com/github/advisory-database), cujo projeto declara licença [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/). Cada registro mantém o link da advisory de origem, e o inventário/cobertura está em [`docs/advisory-snapshot.md`](docs/advisory-snapshot.md). A atribuição está registrada aqui; a revisão jurídica geral dos dados continua pendente antes da publicação.
